# V1.1 新功能使用說明

Hermes V1.1 新增三個工具：**行事曆（Calendar）**、**電子郵件（Email）**、**Python 程式執行（Code Execution）**。

這三個功能有兩種使用方式：
1. **直接下指令**：用 `/calendar`、`/email`、`/run` 明確操作
2. **自然語言對話**：直接跟 Hermes 說，AI 會自動判斷並呼叫對應工具

---

## 一、行事曆（Calendar）

### 原理

事件儲存在 Supabase `calendar` table，每個使用者的資料依 Telegram user ID 隔離，互不干擾。

### 指令用法

#### 新增事件
```
/calendar add <標題> <日期 或 日期+時間>
```

範例：
```
/calendar add 牙醫回診 2025-07-25
/calendar add 週會 2025-07-21 10:00
/calendar add 出差台北 2025-08-01 09:00
```

#### 查看近期事件
```
/calendar list          ← 預設顯示未來 7 天
/calendar list 30       ← 顯示未來 30 天
/calendar list 1        ← 只看今天
```

#### 刪除事件
```
/calendar del <標題關鍵字>
```

範例：
```
/calendar del 牙醫        ← 模糊比對，刪除第一筆符合的
/calendar del 週會
```

### 自然語言用法

直接跟 Hermes 說，不需要下指令：

```
幫我記一下，7月25號要去看牙醫
```
```
下週一早上10點有個會議，幫我加進行事曆
```
```
我這週有什麼行程？
```
```
把牙醫的行程刪掉
```

Hermes 會自動呼叫 `calendar_add`、`calendar_list`、`calendar_delete` 工具完成操作。

### 注意事項

- 日期格式必須是 `YYYY-MM-DD`，時間格式 `HH:MM`（24小時制）
- 刪除是**模糊比對**，只刪第一筆符合的
- 事件依 start_time 文字排序，建議日期格式統一

### 排程提醒（V1.2）

每天 08:00（UTC+8）GitHub Actions 自動觸發，查詢未來 24 小時內的事件，透過 Telegram 推送提醒。

提醒訊息範例：
```
🔔 Upcoming Events Reminder

• 2025-07-21 10:00 | 週會
• 2025-07-21 14:00 | 牙醫回診 — 記得帶健保卡
```

> 提醒只發送給有在 calendar 記錄事件的使用者，空行事曆當天不會收到訊息。

## 二、電子郵件（Email）

### 原理

- **發送**：透過 SMTP SSL 連線（預設 Gmail `smtp.gmail.com:465`）
- **讀取**：透過 IMAP SSL 連線（預設 Gmail `imap.gmail.com:993`）
- 需在 Render 環境變數設定帳號密碼才能使用

### 前置設定

在 Render Dashboard → Environment 設定：

| 變數 | 說明 |
|------|------|
| `EMAIL_ADDRESS` | 你的 Gmail 帳號 |
| `EMAIL_PASSWORD` | Gmail App Password（16位，非帳號密碼） |

> Gmail App Password 申請：[myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)

### 指令用法

#### 讀取收件匣
```
/email inbox            ← 讀最新 5 封
/email inbox 10         ← 讀最新 10 封
```

輸出範例：
```
[1] Mon, 14 Jul 2025
    From: sender@gmail.com
    Subject: 會議通知
[2] Sun, 13 Jul 2025
    From: news@example.com
    Subject: 每週電子報
```

#### 讀取完整內文
```
/email read <序號>      ← 序號來自 inbox 列表，1 = 最新
```

範例：
```
/email read 1           ← 讀最新一封的完整內文
/email read 3           ← 讀第 3 封的完整內文
```

輸出範例：
```
📧 Email [1]
From: sender@gmail.com
Date: Mon, 14 Jul 2025 10:30
Subject: 會議通知
──────────────────────────────
大家好，明天下午兩點會議室開會。
請準時出席。
```

#### 發送郵件
```
/email send <收件人> <主旨> | <內文>
```

範例：
```
/email send friend@gmail.com 你好 | 這是 Hermes 發的測試信！
/email send boss@company.com 請假申請 | 您好，我明天需要請假一天，謝謝。
```

> 注意：主旨和內文之間用 `|` 分隔

### 自然語言用法

```
幫我寄信給 friend@gmail.com，主旨是「週末聚餐」，內容說週六晚上7點見
```
```
查一下我的信箱，有沒有新郵件
```
```
讀最新10封信給我看
```
```
幫我讀第2封信的內文
```

Hermes 會自動呼叫 `email_send`、`email_read` 或 `email_read_body` 工具。

### 注意事項

- 只支援純文字郵件（plain text），不支援 HTML 格式
- 讀取內文上限 3000 字元，超過自動截斷
- Gmail 需使用 App Password，非帳號密碼
- 非 Gmail 帳號可自訂 `SMTP_HOST`、`IMAP_HOST`、`SMTP_PORT`、`IMAP_PORT`

## 三、Python 程式執行（Code Execution）

### 原理

在伺服器（Render）上開一個獨立的 Python subprocess 執行程式碼，有以下保護：
- **Timeout 10 秒**：超時自動終止，防止無限迴圈
- **輸出上限 2000 字元**：超過自動截斷
- **獨立 subprocess**：不影響主程式，錯誤不會讓 bot 崩潰

### 指令用法

```
/run <python 程式碼>
```

#### 數學計算
```
/run print(sum(range(1, 101)))
/run print(2 ** 32)
/run import math; print(math.sqrt(144))
```

#### 資料處理
```
/run data = [3,1,4,1,5,9,2,6]; print(sorted(data))
/run print(list(map(lambda x: x**2, range(10))))
```

#### 日期時間
```
/run from datetime import datetime; print(datetime.now())
/run import time; print(time.strftime('%Y-%m-%d %H:%M:%S'))
```

#### 字串處理
```
/run text = 'Hello Hermes'; print(text.upper(), len(text))
/run print(','.join(['a','b','c']))
```

#### 多行程式碼（用分號串接）
```
/run x=10; y=20; print(f'{x}+{y}={x+y}')
/run import json; d={'name':'Hermes','v':1.1}; print(json.dumps(d,indent=2))
```

### 自然語言用法

```
幫我算 1 到 1000 的總和
```
```
用 Python 算出費波那契數列前 10 項
```
```
現在幾點？用 Python 顯示台灣時間
```

Hermes 會自動生成並執行對應的 Python 程式碼。

### 注意事項

- 執行環境是 Render 伺服器，已安裝 Python 標準函式庫
- **不能**安裝額外套件（`pip install` 無效）
- **不能**存取本地檔案系統（Render 是無狀態環境）
- **不能**發出網路請求（建議改用 `/browse` 或直接問 Hermes）
- Timeout 10 秒，超時會回傳 `[Timeout] Execution exceeded 10s limit`
- 可用的標準函式庫：`math`、`json`、`datetime`、`re`、`random`、`itertools`、`collections` 等

## 三個功能比較

| 功能 | 資料儲存 | 需要設定 | 主要用途 |
|------|---------|---------|---------|
| Calendar | Supabase DB | 不需要 | 記錄行程、提醒事項 |
| Email | 無（直接收發） | Render 環境變數 | 收發 Gmail |
| Code Exec | 無（即時執行） | 不需要 | 計算、資料處理 |

---

## 與 AI 對話的最佳實踐

這三個工具都整合進 Agent Loop，意思是你**不需要記指令格式**，直接用自然語言說就好：

```
明天下午3點有個牙醫預約，幫我記下來，然後查一下這週還有什麼行程
```

Hermes 會在同一次對話中連續呼叫 `calendar_add` 和 `calendar_list` 兩個工具，一次完成。
